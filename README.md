# My Movie Web

## 프로젝트 개요

TMDb API를 활용해 영화 정보를 검색하고 위시리스트를 관리할 수 있는 React 기반 웹 애플리케이션입니다. 인기 영화 조회, 검색, 사용자 인증, 위시리스트 기능을 중심으로 구현했습니다.

## 주요 기능

- TMDb API 기반 영화 검색
- 인기 영화 목록 조회
- 회원가입과 로그인 화면
- 영화 위시리스트 추가/삭제
- 검색 결과 필터링과 정렬
- React Router 기반 페이지 이동

## 기술 스택

- Frontend: React, React Router
- API: TMDb API
- UI: CSS, React Icons, React Toastify
- Deploy: GitHub Pages 정적 배포

## 로컬 실행

```bash
npm install
npm start
```

필요한 API URL과 환경 변수는 `.env.example`을 참고해 로컬 `.env`에 설정합니다.

## 저장소 관리 기준

- 실제 API 키는 Git에 커밋하지 않습니다.
- 빌드 결과물은 배포 목적이 명확한 경우에만 관리하고, 일반 개발 산출물은 Git에서 제외합니다.
